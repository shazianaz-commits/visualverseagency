# Security Policy

## Supported Versions

The following versions of Visual Verse Agency are currently supported with security updates.

| Version | Supported |
|----------|-----------|
| Latest   | ✅ Yes |
| Previous | ✅ Yes |
| Older    | ❌ No |

We recommend always using the latest version to receive the newest security fixes and improvements.

---

## Reporting a Vulnerability

The security of Visual Verse Agency is a top priority. If you discover a security vulnerability, please report it responsibly.

### How to Report

Please include the following information:

- A detailed description of the vulnerability
- Steps to reproduce the issue
- The potential impact
- Screenshots or proof of concept (if applicable)

### Contact

If possible, report vulnerabilities through GitHub's **Private Security Advisories**.

If Private Security Advisories are unavailable, contact the project maintainer directly through GitHub.

> Please **do not** publicly disclose security vulnerabilities until they have been reviewed and addressed.

---

## Response Timeline

We aim to respond according to the following schedule:

| Action | Time |
|---------|------|
| Initial acknowledgement | Within 48 hours |
| Investigation | Within 5 business days |
| Status updates | Weekly |
| Security fix | As soon as possible |

Please note that complex vulnerabilities may require additional investigation time.

---

## Responsible Disclosure

We appreciate responsible disclosure and ask that you:

- Do not publicly disclose vulnerabilities before they are fixed.
- Allow reasonable time for investigation and remediation.
- Provide sufficient information to reproduce the issue.

---

## Supported Components

This policy applies to:

- Website source code
- HTML
- CSS
- JavaScript
- Assets
- Build configuration
- Deployment configuration

Third-party libraries are maintained according to their respective security policies.

---

## Security Best Practices

We are committed to:

- Keeping dependencies updated
- Using secure coding practices
- Regularly reviewing code
- Monitoring reported vulnerabilities
- Applying security patches promptly

Thank you for helping improve the security of Visual Verse Agency.
